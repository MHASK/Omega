A few good questions.

Where does my work live?+

In the folders you choose on your Mac, as Markdown files. Omega also keeps local recovery and undo history. An ordinary notebook stays local until you connect it to Git or give an assistant access.

How does sharing work?+

Connect the same Git repository and branch on each Mac. The repository’s owner manages access through GitHub or GitLab. A shared note link points to a file in that repository; it doesn’t grant new permissions. Live editing additionally needs a trusted relay.

Can I self-host Omega?+

Yes. Install the Mac app and run the open-source collaboration relay on your own server. The self-hosting guide includes Docker Compose, HTTPS, and repository access controls. Everyone connects the same repository, branch, and relay in Settings → Git sync. The relay supports repositories on github.com and gitlab.com; the public Omega relay is not an unrestricted hosting service.

Does the live server keep my notes?+

No notes are written to the relay’s disk. Open documents pass through memory, and a room is forgotten when its last person leaves. Durable files and shared checkpoints live on your Mac and in Git. The relay can read live content, so use one you trust; this is not end-to-end encryption.

What happens when I’m offline?+

You can keep writing locally. Git sync retries when you reconnect. Compatible shared changes merge automatically; when a file needs a decision, Omega offers a full diff and conflict review without discarding either version.

Is Omega free? Which Macs are supported?+

Omega is free and open source under the Apache 2.0 license. The current release supports Apple silicon Macs running macOS 14 or later. Git hosting, an AI client, or a self-hosted relay may have their own costs.
